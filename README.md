# Proyecto1_QAmanual

Proyecto de práctica realizado como parte de mi formación en QA Manual. 

Los objetivos del proyecto se basaron en diseñar y documentar la ejecución de casos de prueba de registro e inicio de sesion en la pagina web "https://practice.expandtesting.com/login".
En los archivos adjuntos se puede observar la documentación y validacion de los CP y posibles BUGS, asi como tambien sus detalles. 
Se realizó la validación de campos obligatorios y reglas de ingreso de datos, verificacion de escenarios positivos y negativos, comparacion de resultados esperados con resultados obtenidos, evidencias de ejecución mediante capturas de pantalla.
